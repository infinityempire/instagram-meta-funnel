# פעולה אחת נדרשת: רוטציית סוד OAuth של Google

בגלל ש־Client Secret של Google OAuth נחשף בעבר במסוף עבודה, יש לבטל את
הסוד הישן וליצור סוד חדש ב־Google Cloud Console. אין לשלוח את הערך החדש
בצ׳אט, לא לשמור אותו בקובץ, ולא להכניס אותו ל־GitHub.

1. פתח את **Google Cloud Console** בחשבון שבבעלותו הפרויקט
   `tal-derie-youtube-upload`.
2. עבור אל **APIs & Services → Credentials**.
3. פתח את לקוח ה־OAuth מסוג **Web application** של Small Stories Hebrew.
4. תחת **Client secrets**, בטל או מחק את הסוד הישן החשוף, ואז לחץ
   **Add secret** כדי ליצור סוד חדש.
5. שמור את הסוד החדש רק במנהל הסודות המאובטח של הפרויקט, באמצעות שדה
   הסודות של סביבת הניהול. אל תעתיק אותו ל־GitHub או לכאן.

לאחר ההחלפה, צריך לעדכן באותו מנגנון מאובטח גם את הגדרת השרת הרלוונטית
ולבצע חיבור OAuth מחדש לפי הצורך. ערכי סוד אחרים שייתכן ונחשפו יש
לסובב במסוף הרשמי שמנהל אותם, ולא לשמור בתיעוד.
