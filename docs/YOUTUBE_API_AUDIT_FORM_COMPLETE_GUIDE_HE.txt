1. מהו הטופס הזה ולמה הוא נחוץ
================================================================

זהו טופס רשמי של YouTube API Services. מטרתו להסביר לגוגל איך
האפליקציה משתמשת ב־YouTube Data API, אילו הרשאות OAuth היא מבקשת,
איך היא שומרת מידע, ואילו פעולות היא מבצעת בערוץ YouTube.

במקרה של Small Stories Hebrew, האפליקציה היא כלי פנימי של בעל ערוץ
אחד. היא מעלה סרטוני ילדים מקוריים בעברית דרך ה־API הרשמי, שומרת
אותם כ־Private כברירת מחדל, מנהלת את המטא־דאטה של הערוץ עצמו, וקוראת
נתוני ביצועים של אותו בעל ערוץ בלבד.

חשוב: הטופס אינו מבטיח אישור, הגדלת מכסה, או אפשרות לפרסם סרטונים
לציבור. רק Google / YouTube יכולים לאשר את הבקשה. עד שתתקבל תשובה
רשמית, אין לשנות נראות של סרטונים ל־Public דרך ה־API.

מצב הבקשה כרגע: לא מאומת. היה דיווח מסוכן חיצוני על מסך קבלה, אבל
לא התקבלה ראיית קבלה עצמאית או הודעת אימות רשמית אצל בעל החשבון.
לכן אין להציג את הבקשה כ"הוגשה" ואין ללחוץ שוב על Submit בלי החלטה
מודעת של בעל החשבון במסך הפעיל שלו.

----------------------------------------------------------------

Target audience:

Free service (we do not charge users)

Does the application display ads on YouTube content?

Do you have a Google / YouTube representative?
No, I do not have a Google representative

Google Developer Documentation

תיאור השירות להדבקה בשדה ההסבר:

Small Stories Hebrew is an internal creator tool for a single owner. It uses the official YouTube Data API through OAuth to upload original Hebrew children’s short-form videos, keep uploads private by default, manage only the owner’s own video metadata, and read the owner’s own video performance data. It is not a public SaaS product, does not provide API access to third parties, does not sell YouTube data, and does not expose other creators’ account data.

אם יש שדה "Does your application use or show YouTube content for
advertising?", התשובה היא No. הכלי אינו רשת פרסום, אינו מוכר נתונים,
ואינו מציג פרסומות על גבי תוכן YouTube.

הסבר OAuth:
הבעלים נותן הרשאה ל־Google OAuth עבור הערוץ שלו בלבד. השרת משתמש
ב־refresh token מוצפן בצד השרת לצורך הפעולות שאושרו, מאפשר ניתוק

- youtube.upload
- youtube.readonly
- yt-analytics.readonly
- yt-analytics-monetary.readonly

בחר רק את קטגוריות השימוש המתאימות בפועל, בנוסח הקרוב ביותר שקיים

- Advertising
- Influencer Marketplace
- שימושים אחרים שאינם מיושמים במערכת

פעולות API בפועל:
- videos.insert: יצירת העלאה resumable של קובץ MP4.
- videos.list: אימות מצב הסרטון לאחר העלאה, לרבות private status ו־Made for Kids.
- קריאות Analytics רשמיות: קריאת מדדי הביצועים של בעל הערוץ בלבד.

לא נעשה שימוש ב־search.list לצורך מוצר זה. אין לבחור אותו אם הטופס
מבקש רשימת endpoints בשימוש.

Visibility / publication policy:
Uploads are private by default. Public visibility changes require explicit
owner approval and are not automated.

Child-directed and AI-content policy:
Every uploaded children’s video is marked Made for Kids. AI-generated or
AI-modified media is disclosed where required.

Expected API requests:
Fewer than 1,000 API requests per day

Requested daily quota:
10,000 quota units per day

Peak requests:
Up to 1,000 requests per day, low and controlled volume

Detailed quota justification to paste:

Planned usage is small and controlled: a few private original-video uploads per day with low-volume status verification and owner-only analytics reads. The requested quota is the conservative 10,000 units per day.

אם יש שדה מפורט יותר על אבטחה, אפשר להדביק את הטקסט הבא:

The service uses official Google OAuth. Refresh tokens are encrypted at rest on the server, OAuth state is signed and short-lived, the owner can disconnect and revoke access, and application logs do not contain OAuth secrets. The service manages only the owner’s own YouTube channel data and does not expose data to third parties.
