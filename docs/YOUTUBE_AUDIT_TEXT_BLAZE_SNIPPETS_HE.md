## תיאור השירות (`auditdesc`)

```text
Small Stories Hebrew is an internal creator tool for a single owner. It uses the official YouTube Data API through OAuth to upload original Hebrew children’s short-form videos, keep uploads private by default, manage only the owner’s own video metadata, and read the owner’s own video performance data. It is not a public SaaS product, does not provide API access to third parties, does not sell YouTube data, and does not expose other creators’ account data.
```
