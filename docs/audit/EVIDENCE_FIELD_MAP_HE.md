# מיפוי ראיות לטופס YouTube API Compliance Audit

הטופס הפעיל דרש ארבעה שדות ראיות ייעודיים לפרויקט. כל קובץ שיוכן עבור אחד מהם חייב להיות קובץ אמיתי, קטן מ־10MB, ולהיבחר ידנית על ידי בעל החשבון.

| שדה ראיות פעיל | קובץ ראיות מיועד | בסיס עובדתי |
|---|---|---|
| Required evidence / system evidence | `01_system_evidence.pdf` | תיאור OAuth רשמי, ברירת־מחדל Private, Made for Kids, הצפנת token וממשק ניתוק. |
| Homepage screenshot | `02_public_service_and_policy_evidence.pdf` | הכתובת הציבורית של השירות ודף מדיניות הפרטיות הציבורי. צילום מסך של `/` לבדו אינו ראיה מתאימה כאשר הוא מציג מסך התחברות/שלד פרטי. |
| Terms of Service | `03_terms_of_service_evidence.pdf` | דף תנאי השימוש הציבורי: `https://instafunnel-lphz3bum.manus.space/terms`. |
| OAuth flow screenshot | `04_oauth_flow_evidence.pdf` | תרשים זרימת OAuth עם state חתום, callback, החלפת קוד, הצפנת refresh token, ניתוק והעלאה פרטית בלבד. |

> אין לבחור, לצרף או להגיש קבצים באמצעות אוטומציית דפדפן. בחירת הקובץ, הפרטים האישיים, ההצהרות וההגשה נשארים פעולות של בעל החשבון במסך הפעיל שלו.
